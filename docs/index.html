A native Rust client for Minecraft Java.

Horizon is an independent client and engine implementation written in Ahead-of-Time Rust. It replaces the Java Virtual Machine runtime with native execution, Vulkan rendering, and sandboxed WebAssembly mods.

Engine Characteristics

Horizon does not emulate or wrap desktop Java jars. Every component is compiled directly to native machine code.

01 / ARCHITECTURE

Native Rust Execution

Built completely in Rust with zero runtime JVM or Dalvik dependencies. Drastically lowers memory allocation and eliminates Garbage Collection pauses during chunk generation.

02 / RENDERING

Direct Vulkan Pipeline

Custom WGSL shader translation via Naga. Directly addresses Qualcomm Adreno and ARM Mali GPUs on mobile hardware with low-overhead draw calls.

03 / EXTENSIBILITY

WebAssembly Mods (.hmod)

Mod extensions run within an isolated Wasmtime sandbox with deterministic memory bounds. Traditional Java bytecode loaders (Forge, Fabric) are not supported.

Legitimate Setup & Preparation

Horizon does not redistribute Mojang game files. Building or running Horizon requires your own legally purchased copy of Minecraft Java Edition 26.3.

1

Own Minecraft Java Edition

Ensure you own a licensed Microsoft / Mojang account with Minecraft Java Edition 26.3 purchased and installed on your computer.

2

Prepare Engine Inputs

Extract and verify the official client jar and asset index matching the repository's cryptographic pins:

python3 tools/android_prepare.py --java-home "$JAVA_HOME"
3

Install ARM64 Native Package

Deploy the compiled release APK to your mobile device (Android 9.0+, ARM64-v8a architecture) and launch:

adb install -r dist/horizon-arm64.apk

Engine Characteristics

Horizon does not emulate or wrap desktop Java jars. Every subsystem runs directly on the device's bare metal.

01 / ARCHITECTURE

Native Rust Engine

Built from scratch in pure Ahead-of-Time Rust. Operates with deterministic RAII memory management, reducing RAM consumption to ~160 MB and eliminating JVM Garbage Collection micro-stutters.

02 / RENDERING

Vulkan 1.1 Pipeline

Custom WGSL shader translation via Naga tuned for Qualcomm Adreno and ARM Mali GPUs. Direct draw calls without intermediate OpenGL translation overhead.

03 / EXTENSIONS

WebAssembly Mods (.hmod)

Mod extensions execute in an isolated Wasmtime sandbox with strict memory safety boundaries. Native performance with guaranteed stability.

04 / COMPETITIVE

PvP Hitmarker & Feedback

Zero-latency in-memory PCM audio synthesizer playing an instant punchy feedback cue paired with responsive hitmarker indicators when striking targets.

05 / OVERLAYS

Keystrokes & CPS Telemetry

Live on-screen WASD and Space key visualizer with a 1,000ms sliding-window frequency tracker for Left and Right click speeds.

06 / CONTROLS

Dual-Mode Touch Engine

Pojav & Bedrock touch layouts, polygon button outlines (Hexagon, Octagon, Circle), full on-screen HUD editor, and virtual mouse.

Legitimate Setup & Preparation

Horizon does not redistribute Mojang game files. Building or running Horizon requires your own legally purchased copy of Minecraft Java Edition 26.3.

1

Own Minecraft Java Edition

Ensure you own a licensed Microsoft / Mojang account with Minecraft Java Edition 26.3 purchased and installed on your computer.

2

Prepare Engine Inputs

Extract and verify the official client jar and asset index matching the repository's cryptographic pins:

python3 tools/android_prepare.py --java-home "$JAVA_HOME"
3

Install ARM64 Native Package

Deploy the compiled release APK to your mobile device (Android 9.0+, ARM64-v8a architecture) and launch:

adb install -r dist/horizon-arm64.apk
